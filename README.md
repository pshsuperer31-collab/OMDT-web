# OMDT · Oriental Musculoskeletal Diagnosis Tool (근골격 감별진단)

근골격계 환자 진료 시, 문진·진찰 소견을 입력하면 **근육 · 관절 · 신경근** 어디의 문제인지 감별해 주는 임상 의사결정 보조 도구.

> ⚕️ 술자의 진단을 대체하지 않습니다. 소견을 감별 패턴으로 구조화할 뿐이며, 최종 판단·확진은 술자의 몫입니다.

O*ST 패밀리(OMST·ODST·OFST·OGST·OPST)의 근골격 감별 트랙. 자세 정렬 스크리닝은 OPST, 통증 원인 감별은 OMDT로 역할을 나눕니다.

## 실행

별도 서버·설치 없이 동작하는 **단일 HTML 파일**. `index.html`을 브라우저에서 열면 됩니다(오프라인·무전송).

## 저장소 구성

```
index.html            배포되는 앱 (단일 HTML, 자립)
tools/                원내 작업용 도구 — 배포 제외 (.vercelignore)
  dx-input.html         진단 데이터 입력·검수 (근육 / 신경 / 인대)
  calib.html            해부 그림 위 근육 좌표 찍기
  highlight-demo.html   좌표 → 표식 점등 데모
  CAPTURE-LIST.html     Z-Anatomy 캡처 체크리스트
img/                  해부 이미지 (로컬 캡처, git 추적 제외 · 좌표 JSON만 추적)
```

`tools/`는 `.vercelignore`로 업로드에서 빠지고, `vercel.json` 리다이렉트로도 한 번 더 막습니다.

## 진단 흐름 (문진 → 진찰 → 감별)

**입력 (아코디언 스크리닝)**

1. 통증 부위 — 9개 부위 + 방사 부위 → 피부분절 선택(신경근 레벨)
2. 발병·경과 — 시기(급성/아급성/만성)·계기·최근 악화 양상
3. 통증 양상 — 성질(둔통·전기양·저림…)·시간(아침경직·야간)
4. 악화 동작 — 굴곡/신전/회전/계단/기침·재채기…
5. 진찰(선택) — Cyriax 선택적 긴장검사·압통점·신경학(감각·근력·반사·긴장검사)
6. 경고 소견

**출력 = 3-way 감별**

- 근육 / 관절 / 신경근 확률 막대(%)
- 우세 원인 + 혼재형 경고
- 신경근 우세 시 레벨 추정(피부분절 → 근절·반사·감각)
- 부위별 구체 구조 지목
- 우세 원인별 추천 확인 검사
- 레드플래그 배너

## 감별 프레임

- **근육·근막(myofascial)** — 과사용·자세성 발병, 저항 등척성 수축 시 통증, 압통점·연관통 (Cyriax: 저항통)
- **관절·관절낭(arthrogenic)** — 아침경직, 능동=수동 같은 방향 제한, 체중부하·계단 악화 (Cyriax: 능수동 일치)
- **신경근(radicular)** — 피부분절 방사통, 저림·전기양, 기침·재채기 악화, 신경긴장검사(SLR/Spurling/ULTT)+, 감각·근력·반사 이상

## 기술

- Vanilla HTML/CSS/JS, 의존성·빌드 없음
- 데이터는 클라이언트 로컬(무전송)
